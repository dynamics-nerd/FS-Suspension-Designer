## Numerical contracts and final coverage rationale

Production-path nominal case: M200kg,g10, four springs30000N/m, explicit synthetic
geometry and tires100000N/m,R0=.25m. Preload derived independently from nominal
circle/rod closure as documented in equations.md. Oracle N_i500N,h=-5mm, zero
angles/travel; PCHIP derivative causes a small sampling error. Integration checks
normal error≤.05N, coordinate error≤1e-5m/rad, while native acceptance remains
forceTolerance1e-5N and momentTolerance1e-6Nm. These are different checks, not a
relaxation of the native balance budgets or historical benchmarks.

Offset CG tests use independent world lever sums: sum(N)=Mg,
sum(X_i*N_i)=Mg*CGx_world and sum(Y_i*N_i)=Mg*CGy_world for explicit mu0. Reflection
permutes left/right normals and reverses roll. Four distinct preloads must alter
pose while preserving balance. Historical ideal cases independently cover tire
compliance, nonzero moving unsprung masses, three-support unilateral contact,
unstable/multiple roots, domain gaps and ill-conditioned/marginal solutions.

The final selection below records actual regression cases, inventory, worker,
legacy MAT, public APIs, Analyzer/DAG, representative performance/memory, source
integrity and Git state. Tests not executed are explicitly unclaimed.
