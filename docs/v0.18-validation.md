## Architectural decisions

Native App Designer shell → `fsdui.View` (presentation/drafts) → `Controller`
(single session/snapshot/resource ownership) → value-only `perform` adapter →
existing public `fsd` APIs. Engineering modules never import the UI package.
Factories retain their own validation and canonical identities; table adapters
preserve outer display metadata as well as physical definitions, references and
unchanged origins. No numerical tolerance, controller or physical equation changes.

Process-based asynchrony is local-only and coarse-grained. It is not a claim of
faster physics. Original seed definitions and adopted registry geometries remain
distinct; no inverse fit or implicit opposite-side adoption is introduced.
