## Incidencias observadas y correcciones

- Incremento B: un recorrido geométrico sin rigidez detectó un bucle MATLAB sobre
  una colección vacía de parámetros. Se hace explícita la fila vacía del bucle;
  el rerun mantiene geometría disponible con mecánica pendiente.
- Analyzer inicial:12 mensajes de alineación/crecimiento acotado. Se corrigió la
  estructura de bloques y se documentó el tamaño fijo del catálogo; el analizador
  final debe confirmar cero, sin desactivar diagnósticos globalmente.
- V23-UI-01: dos intentos de sizing fallaron al editar una tabla anidada bajo un
  panel desplazable. El primer ajuste de ancho no resolvió el desplazamiento
  vertical; la página Parameters propia elimina ese anidamiento y comparte el
  mismo borrador/Apply. El tercer recorrido Desktop pasa esa edición y sizing.
- V23-TEST-01: aserciones iniciales asumían posición de un ledger ordenado por ID,
  igualdad del tiempo de dos ejecuciones y un único identificador de rechazo.
  Se comprueba historial por ID completo, datos físicos excluyendo sólo el tiempo
  observado, y el guard RF correcto (OperationMismatch antes de SemanticMismatch).
  Otra aserción de estabilidad requería seleccionar expresamente la política
  LOWEST_ENERGY_STABLE; UNIQUE_ONLY conserva su contrato histórico. No se cambiaron
  física, tolerancias ni protección de recepción para satisfacer esos tests.
