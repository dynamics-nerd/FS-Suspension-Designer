# V21-F-01 — focused developer correction, 23 October 2026

## Scope and cause

The independent audit reported CHANGES REQUIRED for one MEDIUM finding;
358/358 audit-selected tests passed according to the supplied audit request.
That is external evidence, not a developer rerun. This correction addresses only
opening and continuing a valid incomplete GLOBAL_STATIC configuration.

`globalStaticConfiguration('ROWS',scenario)` dereferenced an empty native tire
as a struct. Controller could load the MAT while presentation failed with
`MATLAB:structRefFromNonStruct`. `GlobalStaticView.refresh` also committed its
drawn-project marker before completing rendering, preventing a subsequent retry
for the same project.

## Change and rationale

- For each of FL/FR/RL/RR, an empty tire leaves the existing blank editable
  cells intact. Available tires and all other rows retain their prior conversion.
  Travel rows are populated independently of tire availability.
- Commit the drawn-project marker after evidence and final status are rendered.
  Propagate exceptions; no catch or substituted physical data disguises failure.
- Existing native readiness owns missing-resource diagnosis and Run availability.
  Existing Apply owns normalization of native numerical settings and inactive
  contact-point declarations. Neither is modified by this correction.

No equations, algorithms in the engineering core, tolerances, units, solver,
readiness, MAT schema, worker protocols or historical evidence are changed.
No new physical assumptions or decisions require approval. The blank-state and
render-completion rationale is recorded under V21-F-01 in decisions.md.
